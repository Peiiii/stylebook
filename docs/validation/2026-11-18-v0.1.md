1. 非开发者：浏览整套风格 → 两项加入比较 → 共享条件检查 → 采用 → 复制 Markdown → 干净预览截图。选择写入 URL，新窗口恢复。

环境：macOS，Node 22.23.2、npm 10.9.8，系统 Google Chrome，Playwright。锁定 React 19.3.1、Vite 8.3.8、TypeScript 5.9.3。默认 Playwright 下载浏览器未安装，配置改为实际可用的系统 Chrome。

- 类型检查、ESLint、生产构建均通过。六项 Playwright 测试通过（22.3秒）；生产预览4173实测详情、隔离预览和按需源码正常，无运行错误。主JS 395.42kB、高亮/源码分块129.26kB（未gzip）。构建按静态宿主输出，hash 路由不依赖 rewrite。
- 浏览器回归 `tests/catalog.spec.ts`：真实入口选型/比较/采用，剪贴板内容，URL 新页恢复；名称/ID/标签检索，无结果恢复；不兼容比较保留选择；复制拒绝的手动文本；无效 ID；18 个条目加载；策略开关/保留周期；Markdown 页签；两场景×两风格×四状态的深色手机渲染及无横向溢出；iframe 加载失败与恢复；外壳明暗独立；选择变化不重载预览。
- 公平比较：iframe 条件共同传递相同 `width/mode/state/scene`；两套共享内容组件，差异由样式边界表达。
- 可复用性：将最终 `Examples.tsx`、`examples.css` 复制到忽略的 `.local/reuse`，新建独立 React 入口，仅安装声明依赖，通过独立 tsc 与 Vite 构建，并在4175独立运行页切换通知、应用设置，读回“记录保留30天”，运行错误为空。Lucide 的 `use client` 指令在纯客户端构建中产生提示，不影响本项目客户端语义。
- 视觉：主代理实际查看桌面目录、详情、比较、完整设置和两套深色手机长页；100% 与 720 CSS px 的 200% 等效重排检查。后者为布局等效检查，不声称真机或原生浏览器缩放验收。

## Review 与边界

最终实现Review：no findings。接入check与git diff --check通过，npm ls依赖完整。项目无既有 diff-only maintainability 脚本，按 development-review 执行 diff-only findings-first 与主观结构复核，不临时造检查器。catalog 是元数据 owner，CatalogStore 是 URL 交互状态 owner，Examples/CSS 是预览及复制源码唯一来源；没有 registry、服务端或平行状态层。源码展示按需加载，避免目录与 clean 预览加载高亮库。

复盘决定：no-increment（长期流程）。本轮新事实已归 README、设计补充及本记录；iframe ready 的局部问题由实现和回归测试修正，不新增全局规则。
